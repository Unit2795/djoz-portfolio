# SnowParticles

A simulated 2D snowfall effect using HTML canvas.

Key Features:
- Density
  - Number of particles scales up and down based on screen size to keep a consistent number of particles in the viewport
- Velocity
  - The speed of the particles can be adjusted to be a random speed (pixels per second) within a range.
- Angle
  - An angle range can be supplied and particles will randomly travel in the direction of this angle.
- Opacity/Color/Size
  - The opacity, color, and size of the particles can be modified 
- Resizing
  - When the screen is resized, particles will not jolt or spawn unnaturally.
