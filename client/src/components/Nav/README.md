# Navbar
Key features:

1. **Responsive**
    1. The navbar displays differently on desktop and mobile devices.
    2. Hamburger button can be used to open/close the mobile menu
    3. Clicking a nav anchor will close the mobile menu
2. **Scroll Resize**
    1. When scrolling down the page, the navbar scales up horizontally to the full width of the page. This allows more of the hero/intro to be visible and creates a nice effect
3. **Highlighting**
    1. If a user uses the scroll bar, mouse wheel, or otherwise scrolls the site, the nav anchors will update their highlight properly based on what content is the most visible on the page.
    2. When a nav anchor is clicked, it is highlighted properly and the site scrolls smoothly to the selected section.
4. **Accessible**
    1. Is the user prefers reduces motion, the navbar will start at full width and all animations will be disabled.
5. **JS Optional**
    1. This navbar can function without JS, but will lack some functionality
